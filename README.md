📊 HabitTrackerCLI

HabitTrackerCLI é uma aplicação Java em linha de comando (CLI) desenvolvida para o rastreamento de hábitos, com foco inicial no uso consciente de redes sociais como Instagram e TikTok.

O projeto foi criado como um projeto pessoal de aprendizado, com ênfase em lógica de programação, boas práticas, organização de código e integração com banco de dados, evitando frameworks e interfaces gráficas no início para reforçar os fundamentos.

🎯 Objetivo do Projeto

- Incentivar o uso consciente de hábitos digitais

- Registrar e acompanhar o tempo gasto em redes sociais

- Consolidar fundamentos de programação em Java

- Praticar integração com banco de dados relacional (MySQL + JDBC)

- Servir como base para futuras evoluções (API REST, Spring Boot, deploy)

🛠️ Tecnologias Utilizadas

- Java

- MySQL

- JDBC

- Git & GitHub

📌 Funcionalidades

- Registro de usuários com limite diário de uso

- Login de usuários

- Registro de hábitos (tempo gasto por rede social e por dia)

- Cálculo automático do total diário de tempo gasto

- Alerta quando o limite diário é ultrapassado

- Visualização do histórico completo de hábitos

- Persistência de dados utilizando banco MySQL


🧠 Principais Aprendizados

Durante o desenvolvimento do projeto, foram trabalhados conceitos como:

- Padrão DAO (Data Access Object)

- Relacionamento entre tabelas e Foreign Keys

- Tratamento de exceções SQL

- Uso correto de PreparedStatement

- Manipulação de datas com LocalDate e DateTimeFormatter

- Controle de fluxo com menus e loops

- Problemas reais com entrada de dados (Scanner)

- Debug de erros comuns em aplicações Java + MySQL
